# ADR 004. В дереве показывается суммарная численность, а не собственная

**Статус:** принято · этап 2

## Контекст

API отдаёт собственные показатели узла, без потомков: у отдела «Платформа»
`headcount: 2` — это руководство отдела, тогда как в его четырёх командах
работают ещё 43 человека.

На этапе 1 дерево показывало именно `node.headcount`, буквально по формулировке
задания «каждый узел показывает name, headcount и цветовой индикатор
performance». Выглядело это так:

```
Платформа                    2 человека
  Ядро платформы            12 человек
  Инфраструктура             7 человек
```

Отдел из двух человек, внутри которого 43. Вопрос «это так задумано или я чего-то
не понимаю» возник у первого же человека, открывшего интерфейс.

## Решение

В дереве показывать агрегат по поддереву. Собственная численность уходит в
подсказку: «Собственных 2, в подразделениях 43».

Причина в том, какой вопрос задаёт человек, глядя на строку дерева. Увидев
«Инженерия», он спрашивает «сколько людей в инженерии» — ответ 108, а не 5.
Собственная численность отвечает на другой вопрос, который на этом экране почти
никогда не задают.

То же касается эффективности: в дереве показывается средневзвешенная по
поддереву, а не собственный показатель узла. Иначе дерево и таблица показывали бы
для одного узла разные числа.

## Альтернативы

**Показывать оба числа**, например «2 / 45». Отклонено: две колонки цифр в
каждой строке ради значения, которое нужно изредка, и непонятно без легенды.

**Оставить собственное, объяснив подсказкой.** Так и было. Подсказка не
помогает: список просматривают глазами, а не наводят курсор на каждую строку.

**Считать агрегат на сервере.** Противоречит заданию — агрегация на клиенте и
есть проверяемая часть работы.

## Последствия

- Дерево зависит от агрегатов, то есть `aggregateTree` должна быть посчитана до
  первой отрисовки. Она и так считается один раз на набор данных.
- Числа в дереве и в колонке «Всего сотрудников» совпадают по построению:
  источник один.
- Формулировка задания выполняется по сути: узел показывает численность —
  просто ту, которая на этом экране осмысленна.
